📊 Tipos de datos en Oracle SQL Developer Data Modeler · 23.x

Clasificación, propósito y escenarios recomendados · Incluye tipos modernos 21c/23ai (BOOLEAN, VECTOR)
# Categoría Tipos principales Propósito / Escenarios recomendados
🔵 1 Numéricos NUMBER(p,s) · FLOAT(p) · BINARY_FLOAT · BINARY_DOUBLE · BOOLEAN (21c/23ai) IDs, contadores, dinero, cálculos científicos. Regla de oro: dinero → NUMBER(p,s) con escala fija. Nunca BINARY_FLOAT/DOUBLE para finanzas. INTEGER, INT, SMALLINT son alias → NUMBER(38).
🟢 2 Fechas y Horas DATE · TIMESTAMP(p) · TIMESTAMP WITH TIME ZONE · TIMESTAMP WITH LOCAL TIME ZONE · INTERVAL YEAR TO MONTH · INTERVAL DAY TO SECOND Nacimientos, vencimientos, auditoría fina, eventos globales, duraciones (SLA, contratos, antigüedad). DATE = fecha + hora hasta segundo. TIMESTAMP(p) = fracciones de segundo. WITH LOCAL TIME ZONE normaliza a zona de la BD.
🟡 3 Cadenas de Texto CHAR(n) / NCHAR(n) · VARCHAR2(n) / NVARCHAR2(n) · LONG (obsoleto) · CLOB / NCLOB Nombres, emails, títulos, códigos ISO, texto largo (artículos, XML, JSON). Oracle no tiene ENUM → usar CHECK constraints o tabla catálogo. LONG obsoleto: usar CLOB. NCHAR/NVARCHAR2 siempre Unicode (AL16UTF16).
🟠 4 Binarios y LOBs RAW(n) · LONG RAW (obsoleto) · BLOB · BFILE UUIDs, hashes, tokens cifrados, archivos grandes. RAW hasta 2000 bytes. BLOB 4 GB (128 TB con MAX en 23ai). BFILE = puntero a archivo externo (no almacena contenido). Consejo: archivos grandes → ruta en BD + archivo en S3/disco.
🟣 5 JSON VARCHAR2 · CLOB · BLOB (con IS JSON) · tipo JSON nativo (21c+) Payloads de API, atributos variables. Validación: CHECK (col IS JSON). Consultas: JSON_TABLE, JSON_VALUE, JSON_QUERY, dot notation (col.campo). 21c+ permite almacenamiento OSON y consultas rápidas.
🔴 6 Identificadores y Otros ROWID / UROWID Identificador físico interno de cada fila. Solo para accesos ultrarrápidos puntuales; no como clave de negocio (cambia al mover la fila). UROWID: tablas externas, vistas materializadas.
🟤 7 Espaciales SDO_GEOMETRY · POINT · LINESTRING · POLYGON (+ variantes MULTI*) Ubicaciones GPS, rutas, zonas, límites. Requiere Oracle Spatial (Locator incluido en todas las ediciones). Índices R-tree y operadores espaciales (SDO_CONTAINS, SDO_DISTANCE, etc.).
⚫ 8 Vector (23ai) VECTOR(n, format) ej. VECTOR(1536, FLOAT32) Embeddings para búsqueda semántica / RAG con IA. Formatos: INT8, FLOAT32, FLOAT64. Distancias: cosine, euclidean, dot. Índices IVF o en memoria. Disponible en Oracle 23ai.
